# Known-FAILREPRO registry for the hermetic micro corpus (dis86/data/sst/micro/)

# real, hand-picked test. These entries are regression fixtures, NOT bugs to be
# hidden: the cargo-test lane (dis86/src/emu86/sst/micro.rs) runs each one
# through the real runner and asserts it diverges EXACTLY as recorded here
# (bucket + detail, keyed by SHA1). See docs/emu86/sst.md for the full P3
# divergence ledger; `cluster` links to its classification (SST-D-XXX).
#
# Contract: when a future emu86 fix flips one of these entries to PASS, the
# lane FAILS. That failure is the signal to (a) drop the entry from spec.txt,
# (b) regenerate the corpus, and (c) move the entry from this file + the
# expectations table in micro.rs into the PASS list. Do not weaken the
# assertion instead.
#
# File naming: <form>.MOO, one per family, mirroring the source form stem so the
# lane applies the same per-form policy flag umask as the CLI.
#
